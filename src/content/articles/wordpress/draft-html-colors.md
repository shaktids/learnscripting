Colors are very important to give a good look and feel to your website. We can specify colors on page level using &lt;body> tag or you can set colors for individual tags using bgcolor attribute.

The &lt;body> tag has following attributes which can be used to set different colors −

- **bgcolor** − sets a color for the background of the page.
- **text** − sets a color for the body text.
- **alink** − sets a color for active links or selected links.
- **link** − sets a color for linked text.
- **vlink** − sets a color for *visited links*.

## Background Color:

```
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta http-equiv="X-UA-Compatible" content="IE=edge">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>HTML Color</title>
</head>

<body>
    <h1 style="background-color:DodgerBlue;">Hello World</h1>

    <p style="background-color:Tomato;">Lorem, ipsum dolor sit amet consectetur adipisicing elit. Cumque, maiores
        recusandae porro facilis quasi incidunt?</p>
</body>

</html>
```
