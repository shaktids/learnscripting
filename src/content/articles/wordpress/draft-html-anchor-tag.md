An anchor tag is a HTML element that creates a link to a target URL. When correctly implemented, the link can help to create text, images, or as buttons, so that users can interact with it and visit the link's destination.

## Syntax of HTML anchor Tag:

```
<a href="https://www.google.com.com">Go to the website </a>
<a href="path\file_name.html">Go to next Page</a>
```

## Example of HTML Anchor Tag:

```
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta http-equiv="X-UA-Compatible" content="IE=edge">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>HTML Link</title>
</head>
<body>
  <p><a href="https://learnscripting.org/" target="_blank">Go to the website</a></p>
</body>
</html>
```
