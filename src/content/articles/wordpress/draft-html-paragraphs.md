HTML paragraph or HTML p tag defines a paragraph of a text in a web page. The content is written between the opening (&lt;p>) and closing (&lt;/p>) tags. If the closing tag is omitted, it is considered that the end of the paragraph matches with the start of the next block-level element.

## Example:

&lt;p>This is the first paragraph&lt;/p>

&lt;p>This is the second paragraph&lt;/p>

&lt;p>This is the third paragraph&lt;/p>

&lt;p>This is the fourth paragraph&lt;/p>

## Example of HTML p tag:

```
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta http-equiv="X-UA-Compatible" content="IE=edge">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>paragraph</title>
</head>

<body>
    <p>This is first paragraph</p>
    <p>This is second paragraph</p>
    <p>This is third paragraph</p>
    <p>This is fourth paragraph</p>

</body>

</html>
```
