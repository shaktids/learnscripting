HTML style element is used to change the style of a  HTML element. There is also a default style for every HTML element e.g. background color is white, text color is black etc.

## The syntax of style attribute is:

```
style= "property:value"
```

## HTML style Text color:

Example:

```
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta http-equiv="X-UA-Compatible" content="IE=edge">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>HTML style</title>
</head>
<body>
  <h2 style="color:blue">This is blue heading </h3>
  <h3 style="color:brown">This is brown heading</h3>
</body>
</html>
```

## HTML Style font-size:

Example:

```
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta http-equiv="X-UA-Compatible" content="IE=edge">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>HTML style</title>
</head>
<body>
  <h3 style="font-size:100%">This is a heading</h3>
  <p style="font-size:500%">This is a paragraph</p>
</body>
</html>
```
