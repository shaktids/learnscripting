In our previous post we have discussed about the python Installation.Also we have discussed how to setup path .In this tutorial we will start writing our first program "Hello World" using python. We will use pyhton IDE Pycharm Community Edition for writing all our programs.Before going to use the IDE we will test the Pyhton default installed editor (IDLE).To open IDLE you can open by search in start menu or you can go to the pyhton installation folder and open the IDLE. Once you will open the IDLE it will open an GUI like below image.

As you can see in the above image we have to start writing pyhon code after the  >>> mark .When we will start writing a script after a line we have to press enter.Then the phthon interpreter will consider as this is an end of a line.

In the below image we have written an simple program.To keep a value and to print it.For storing the variable we have taken **i** as a variable and assign the value as 5. As you can see in on e line i have taken value as 5.And in another line i have printed the value.So using this editor we can write Python  program and save as .py extension.But this editor has some limitation that we can not run a piece of code without running from the beginning.Which is not necessarily always needed.

To avoid all these limitation we will use pyhton editor as pycharm to make our life easy.You have to download the pycharm [editor from this link](https://www.jetbrains.com/pycharm/download/#section=windows).Please remember to download the community edition which is free for the lifetime.
