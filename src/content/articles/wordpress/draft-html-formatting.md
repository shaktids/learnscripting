HTML  holds a special character to format text without using CSS. There are 14 formatting tags in HTML such as &lt;b>,&lt;strong>,&lt;i> etc.

HTML Formatting Elements are:

|  |  |
| --- | --- |
| **Tags** | **Description** |
| &lt;b> | Bold text |
| &lt;strong> | Important text |
| &lt;i> | Italic text |
| &lt;em> | Emphasized text |
| &lt;mark> | Marked text |
| &lt;u> | Underline text |
| &lt;tt> | Teletype Text (not supported in HTML5) |
| &lt;strike> | To draw a strikethrough on a section of text. (Not supported in HTML5) |
| &lt;sup> | Superscript text |
| &lt;sub> | Subscript text |
| &lt;del> | Deleted text |
| &lt;ins> | Inserted text |
| &lt;big> | Bigger text |
| &lt;small> | Smaller Text |

## Example of &lt;b> tag:

```
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta http-equiv="X-UA-Compatible" content="IE=edge">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>paragraph</title>
</head>

<body>
    <p>This is a paragraph</p>
    <b>The text is bold</b>
</body>
</html>
```
